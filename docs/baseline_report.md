## 1. What was evaluated

Non-adapted baseline for cross-subject seizure **detection** (not prediction) on CHB-MIT, 18 bipolar channels,
4 s windows with 50 % overlap, 32 features per channel (576 columns; 30 per channel if entropy is disabled).

| Item | Setting |
|---|---|
| Protocol | Leave-One-Subject-Out by `patient` (`chb21` is patient `chb01`) |
| Models | RBF-SVM and Random Forest, each in `Pipeline(StandardScaler, SelectKBest(f_classif, k=100), classifier)` |
| Class imbalance | class weights; training data subsampled to 5:1 interictal:ictal (cap 30 000 windows); held-out patient never resampled |
| Tuning | `TBD: nested (GroupKFold by patient, 3 inner splits) or fixed` |
| Arm `raw` | features unchanged |
| Arm `subject_standardised` | per-patient z-score using that patient's first 10 min (300 windows) of interictal data before its first seizure |
| Scoring | identical windows in both arms: each patient's calibration windows are excluded from scoring in both |
| Cohort | `TBD: number of patients, seizures, hours; deviations from README (for example entropy disabled, subset of patients)` |

## 4. Limitations

1. **False alarms per hour is not a clinical false-alarm rate.** Seizure-free data is capped per patient, and
   the value is computed as `fp / (n_windows * step_s / 3600)` on the included data only.
2. **Window-level scoring, not event-level.** Onset latency and the number of alarm events per seizure are not
   measured. Neighbouring windows overlap by 50 %, so window decisions are correlated.
3. **Small and uneven seizure counts.** Some patients have only a few seizures, so their per-patient metrics
   are noisy; medians are reported next to means. Metrics that are undefined for a patient (for example no
   ictal window left after windowing) are NaN and excluded from the aggregates.
4. **Calibration windows are chosen with labels.** They are the first interictal windows before the patient's
   first seizure. In deployment the seizure-free assumption cannot be checked this way.
5. **Standardisation is only as good as the calibration segment.** A feature that is constant during
   calibration has its SD floored at `eps = 1e-8`, which amplifies any later deviation; such features are logged
   per patient. If a patient has fewer than 60 usable windows before the first seizure, the first 300
   interictal windows overall are used instead (this is logged and can include post-seizure windows).
6. **Selection of the class-imbalance strategy, the feature count (k = 100) and the small hyper-parameter grids
   was fixed in advance, not optimised here.** Differences between SVM and RF may partly reflect this.
7. **Cohort restrictions.** Seizure-free hours are capped per patient (`max_seizure_free_hours_per_patient`),
   `chb21` is merged into `chb01`, and any further deviations are listed in Section 1 (`TBD`).
8. **Filter delay (Member A, for the wearable discussion).** The 0.5-45 Hz linear-phase FIR is long (about 2 s
   group delay), which is acceptable offline but is a cost for wearable use.
9. **This baseline is what adaptive filtering (Milestone 2) must beat**, in particular the
   `subject_standardised` arm: a simple per-patient standardisation already removes part of the inter-subject shift.
